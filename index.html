The shape of a
viral fork's first days.

Days after it launched, Odysseus drew a flood of pull requests from contributors. These charts describe that flood — who shows up, what gets merged, and how the project's commit conventions shifted early on. Every figure is computed from the public GitHub API and git history; the snapshot refreshes on a schedule.
